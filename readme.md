# 聚合图床

为 Picora 添加 [聚合图床](https://www.superbed.cn/)（Superbed）图片上传支持。一个插件同时提供两种鉴权方式，新建配置时选择其中一种即可：

- **账号密码**：用聚合图床网页版账号登录，不需要 API Key，也不需要会员。
- **API Key**：使用聚合图床用户中心签发的 API Key 上传，需要该账号具备 API 上传权限。

此插件使用新版Picora提供的鉴权选择功能，**要求 Picora 1.1.0 或更高版本**，不符合要求可能无法正常安装。

## 使用

1. 在 Picora 中安装此 ZIP 插件。
2. 仓库页点「添加配置」，在搜索里选择「聚合图床」。
3. 在「登录方式」下拉框里二选一，表单只显示该方式需要的字段：

| 登录方式 | 需要填写 | 适用情况 |
| --- | --- | --- |
| 账号密码 | 聚合图床账号（邮箱或用户名）、账户密码 | 未订阅会员、只想用网页账号上传 |
| API Key | 聚合图床 API Key | 账号已有 API 上传权限 |

4. 选择图片上传。

## 说明

### 账号密码方式

- 先向 `https://www.superbed.cn/api/v1/auth/login` 登录：账号包含 `@` 时只发送 `email` 字段，否则只发送 `username` 字段，密码只出现在登录请求里。
- 登录成功后访问令牌暂存在内存中，上传走同一主机的 `https://www.superbed.cn/api/v1/upload/`，请求只带令牌和图片。令牌 30 分钟过期，上传遇到 401 时自动重新登录一次并重试。
- 网页版对超过 10 MiB 的图片会改用分块上传，本插件只实现普通单文件上传，建议使用不超过 10 MiB 的图片。

### API Key 方式

- 请求发往 `https://api.superbed.cn/upload`，以 `X-API-Key` 请求头传递密钥，以 multipart/form-data 的 `file` 字段发送图片。
- 只有 HTTP 200 且响应 `err` 为数字 `0` 时才视为成功，错误说明从 `msg` 读取。
- API Key 需要订阅会员后在聚合图床用户中心获取；不满足条件请改用账号密码方式。

### 通用

- 两种方式都只支持上传，图床管理、删除请前往聚合图床账号后台操作。
- 本插件依据 2026 年 10 月的网页版与开放接口流程编写，属于第三方非公开接口适配，网站更新后可能失效。

## 常见错误

| 提示 | 处理 |
| --- | --- |
| 账号或密码错误 | 用浏览器登录网页版确认账号密码；邮箱账号要填完整邮箱 |
| 登录已失效 | 稍后重试；反复出现请重新编辑配置确认密码 |
| API Key 无效或已过期 | 在聚合图床用户中心重新生成 API Key |
| 上传被拒绝 | 账号状态异常、免费额度用尽或缺少 API 上传权限 |
| 图片超过图床允许的大小 | 压缩图片或改用其它图床 |
